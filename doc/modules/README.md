# HyperTrade Modules

This directory documents the main HyperTrade responsibilities and where they currently live in the repository.

- [Data](data.md): market data, indicator cache, and external data access.
- [Features](features.md): indicator hydration and feature preparation.
- [Signals](signals.md): external signal loading, filters, acceptance policy, and ranking.
- [Simulation](simulation.md): market-time handling, trade simulation, backtest metrics.
- [Optimization](optimization.md): Optuna multi-objective study execution and Pareto candidate selection.
- [Experiments](experiments.md): experiment artifact registry and benchmark suite orchestration.
- [Reporting](reporting.md): run, suite, and table loading for analytics surfaces.
- [UI](ui.md): Streamlit dashboard pages and launcher workflow.
